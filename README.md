# Theme Studio

Hier liegen die Updates für Theme Studio (geschlossene Alpha).

- `updates/latest.json` – aktuelle Version, unterschrieben mit dem Theme-Studio-Schlüssel
- `updates/ThemeStudio-Setup-<Version>.exe` – das Setup dazu

Das Programm sucht beim Start selbst nach neuen Versionen. Dateien, die nicht richtig unterschrieben sind, installiert es nicht.
